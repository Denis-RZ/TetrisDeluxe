玩法說明

兩種模式，兩種決策

Classic

手動放置方塊、消除行數並挑戰更高分。開啟 BOT 可用於自動遊玩練習或展示；關閉後即可恢復手動控制。

Tactical Campaign

挑戰十個關卡，與 BOT 比較分數，在步數限制內達成目標。對手 BOT 一直是模式的一部分；BOT 開關決定玩家一側由手動或自動操作。

操作方式

  • 點擊 — 旋轉
  • 向左/右滑動 — 移動
  • 向下滑動 — 加速下降
  • DROP 按鈕或向上滑動 — 直接落下
  • HOLD — 暫存方塊
  • PAUSE — 在遊戲中安全暫停
